## Key Decisions

### 1. Six 1979 slips are corrected, not reproduced (owner rulings, 2026-11-10)
The plan's governing principle is "reproduce the story as coded"; the owner carved out an exception for six slips where the line's intent is evident: "not this time - let's infer the correct actions for the bugs" (O-8 FILL ends the program, O-9 JUMP fires the laser and ends the program, O-10 READ WATER prints the penny's legend), "yes those two as well" (O-1 LEASH names the rat — reversing the 2026-09-14 REPRODUCE ruling; O-11 the rat's bite can never happen), and "yes" (O-12 line 2140 is unreachable, so the cat never needs its leash). Consequence: for these commands the oracle and the port differ on purpose, and Phases 6 and 7 must not generate oracle cards for them (recorded in `plan.md`). No ADR, by the owner's standing position for this repo.

### 2. Generate once, hand-maintain after (Phase 3)
`story/` is hand-edited from the generated base; `world_parity.py` is the guard (the scaffold-equality test was removed in Phase 4).

### 3. Every exit is one-way (Phase 3)
Exits mirror the 1979 14-column exit matrix rather than Chord two-way connections.

### 4. Verbs are story-defined actions, one per 1979 handler (Phase 4)
Each handler's 1979 behaviour stays in one `define action`, not stdlib reuse.

### 5. Death is a story state, not the game ending (Phase 4)
The 1979 game continues after death, so death is a state handled by an every-turn rule.

### 6. Verb tests take every expectation from the oracle at run time (Phase 4)
No expected value is hand-written; a corrected slip is tested by asserting both the oracle's slip and the port's correction.
