## Key Decisions

### 1. Generate once, hand-maintain after (Phase 3)
The world was generated from the decode; `story/` is hand-edited from here and `world_parity.py` is the guard. Phase 4 made that real: the scaffold-equality test was removed.

### 2. Every exit is one-way (Phase 3)
Exits mirror the 1979 14-column exit matrix rather than Chord two-way connections.

### 3. Verbs are story-defined actions, one per 1979 handler (Phase 4)
Everything other than going and looking is a `define action` per original handler, not stdlib reuse, so each handler's 1979 behaviour stays in one place.

### 4. Death is a story state, not the game ending (Phase 4)
`kill the player` ends the game, but the 1979 game continues after death, so death is a state handled by an every-turn rule.

### 5. Verb tests take every expectation from the oracle at run time (Phase 4)
No expected value is hand-written; the test plays the oracle and the port and compares. No ADR written (owner's standing position for this repo).
