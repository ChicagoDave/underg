The oracle writes UNDER?.DAT save files that persist between runs, and line 20's password generation changes on each run, so a fresh checkout or unclean working directory produces a different password than a prior recorded transcript. The card-generation tooling (Phase 6) and any golden-transcript regeneration must clean these files before each run or pin/capture the password per run.
